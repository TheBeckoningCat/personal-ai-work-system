# Departments

No departments are set up in this starter. A department head is added only when the owner asks for one, using [How we add and retire personas](../80%20SOPs/08%20Assistants%20and%20Their%20Roles/How%20we%20add%20and%20retire%20personas.md).

## Mission Statement

The workspace keeps one owner's notes, commitments and AI helpers in a shape a later session can still use. The executive unit keeps the shared rules, the Mail Room and the design. The Hub keeps capture and the calendar of record. Each other unit keeps its own subject. The owner names the workspace and decides what is added. Helpers propose. They don't widen their own authority.
