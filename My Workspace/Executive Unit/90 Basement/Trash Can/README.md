# Trash Can

The one Trash Can for the whole workspace. Move things here instead of deleting them, into a folder named for the unit they came from, made the first time it's needed. Write down the original path, the date, why it moved and how to put it back. Never overwrite anything here. Emptying the Trash Can is the owner's call, never a helper's. See [Keeping, archiving and the Trash Can](../../80%20SOPs/07%20Files%20and%20Deleting/Keeping%2C%20archiving%20and%20the%20Trash%20Can.md).

Each unit's `90 Basement/Archive/` and `90 Basement/Resources/` are made the first time something is filed there.
