# End Session

Do this once, when the owner says to wrap up or the work is done.

1. Start nothing new. On each project sheet you touched, write where it stands and the next step.
2. Answer or file the mail you took. Anything unfinished goes back on its project sheet marked waiting.
3. Put new dates in the unit calendar and anything waiting on the owner in [Needs the Owner's Decision](../../Needs%20the%20Owner%27s%20Decision.md).
4. Add one line to your Work Log, then rewrite your Desk note so the next session knows what to do first.
5. Run `python3 Setup/Tools/check_package.py --mode workspace` and fix any broken link it finds.
6. Mark your [Session Log](Section%201/Session%20Log.md) row `out` with the time, then tell the owner what got done, where it is and what's still open.

If you can't save files, give the owner the exact lines to save and don't say they're saved until they are. Never make up work or a time to make the session look finished.

Your Work Log is `Work Log/YYYY-MM.md` in your office, one line per session. Make it from the [Work Log template](../Templates/Work%20Log.md) the first time. If you can't run Python, open each link you wrote this session and check it lands on the right page. Don't close another app or stop someone else's session, and don't leave a background job running.
