# Hosts

A host is the app or tool around the AI: a chat app, an agent, a command line tool. The model writes the answers. It can only open files if its host gives it a way to. Agent and CLI describe how a host works. Neither name gives more permission.

## Working Host

A host that can read the workspace folder follows Start Here as a named persona. Say plainly what you can read, save and run. If you can read but not save, give the owner the exact lines to save, and never say something is saved when it isn't. If you couldn't read a whole required page, your start isn't complete. Don't stop other hosts or start background work as part of a session.

## Guest Host

A Guest Host works from a prepared packet instead of the folder, like a browser chat. It either takes on a named persona for a session or helps with one job as an invited helper. [Guest Start](../Guest%20Start.md) has the packet list and the return. A guest never claims to have read a file that wasn't in the packet.

## One persona, more than one host

An agent or a command line tool may lead, and another host may help or take over later. The owner decides how the work is split.

1. Each session gets its own row in the [Session Log](../Section%201/Session%20Log.md).
2. Name the job and the pages it touches in Current Work before you start. Don't take a partner's job without agreeing.
3. Work in different files when you can, or pick one writer for a shared page. Read it again right before you save.
4. To hand a job over, write a switch note on your Desk: the job, what's done, what's next, and who takes it. The job moves only when the other host says it has it.
5. Keep your notes under your own session heading on the Desk. Being the last one out doesn't mean a daily routine still needs to run.

Handing work to another host never adds permission for either of you.

## Words

A session is one sitting with its own ID. A named persona has a profile and a row in the Staff Directory. An invited helper only gets what the job needs and doesn't claim a staff name. If you lose your place, read the pages again and check the saved records. Don't invent a closing record.
