# Workshop and Storeroom

A Workshop holds live work that isn't a note, like code or design files. A Storeroom holds finished work you want to keep. Both stay outside the workspace, and so do client folders. None are set up in this starter.

Before a helper touches an outside folder, the owner names the path, what it's for, which files may be used and what needs a yes. Record that here. A line on this page is not permission to open outside files. Only the folders under [Where I can work](../../Boundaries.md#where-i-can-work) are. The [Site Card](../Templates/Site%20Card.md) and [Client Card](../Templates/Client%20Card.md) templates help when you add one.
