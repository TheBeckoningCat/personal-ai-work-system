# Lessons SOP

A lesson is something you noticed that should help next time. Write it in `Lessons.md` in your office, made the first time, using the [Lessons template](../../Templates/Lessons.md). Put the date, the session and what you saw, and mark it unproven. A fact about one project stays on that project.

Watch for it again. Two later cases that really fit are enough to suggest it's proven. The owner can turn it down or reword it.

A lesson never changes a persona's job, a rule or a procedure by itself. Propose the actual change and get the owner's yes first. End Session can note a lesson from that session. Nothing collects lessons on its own.
